# Modul 1: Pemrograman Mobile - Bahasa Pemrograman Dart

Dokumentasi dan kode implementasi materi **Modul 1: Bahasa Pemrograman Dart** untuk praktikum Pemrograman Mobile.

## Daftar Berkas Praktik
1. `01_hello_world.dart`: Program dasar menampilkan output ke konsol.
2. `02_tipe_data.dart`: Eksplorasi tipe data `int`, `double`, `String`, `bool`, dan `var`.
3. `03_operasi.dart`: Operasi matematika, perbandingan, pembagian bulat, dan logika.
4. `04_struktur_kontrol.dart`: Percabangan `if-else` serta perulangan `for` dan `while`.
5. `05_fungsi.dart`: Pembuatan fungsi standar dan arrow function `=>`.
6. `06_kelas_dan_objek.dart`: Pemrograman Berorientasi Objek (OOP) — kelas, atribut, konstruktor, dan method.
7. `07_import_library.dart`: Mengimpor dan memanfaatkan library bawaan `dart:math`.
8. `08_eksepsi.dart`: Penanganan error runtime menggunakan `try`, `on`, `catch`, dan `finally`.
9. `09_async_await.dart`: Pemrograman asinkronus menggunakan `Future`, `async`, `await`, dan `Future.delayed`.
10. `main.dart`: Rangkuman eksekusi seluruh konsep Modul 1 dalam satu berkas.

## Cara Menjalankan
Pastikan Dart SDK telah terpasang, lalu jalankan perintah:
```bash
# Menjalankan demonstrasi utama
dart run main.dart

# Atau menjalankan berkas spesifik
dart run 01_hello_world.dart
dart run 06_kelas_dan_objek.dart
dart run 09_async_await.dart
```
